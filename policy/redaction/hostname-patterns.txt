# Each fragment should identify a real internal domain or naming pattern for
# this district (e.g. "\.internal\.example-district\.k12\.wa\.us$"). Blank
# lines and lines starting with "#" are ignored. This file ships empty in the
# public repo. reusable-iac-checks.yml and reusable-onprem-checks.yml run
# redact-check.sh against this copy without setting REDACT_HOSTNAME_FILE, so
# their redaction-check job applies no hostname patterns. To check for a
# district's own domains, keep a patterns file outside this repo (like
# <district-id>.env.yml) and run redact-check.sh locally with
# REDACT_HOSTNAME_FILE pointing at it.
