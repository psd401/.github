# Code of Conduct

This organization follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, no harassment of any kind. This is a public school district's codebase — behave like students might be reading, because they might be.

Enforcement: violations may result in comment removal, PR/issue locks, or organization bans. Report conduct issues privately to Technology Services.
